# LeafOS Procedures

Procedures turn fixes that should apply across LeafOS into reusable operating
rules. They complement feature documentation: a procedure describes how to
detect the host, classify failures, produce repair guidance, and gather enough
evidence to distinguish a product defect from a local environment problem.

- [Shell compatibility and user-error triage](SHELL-COMPATIBILITY-AND-USER-ERROR-TRIAGE.md)

New PowerShell, Bash, WSL, Git Bash, and CMD-facing launchers should follow the
shell procedure unless a stricter subsystem contract says otherwise.
